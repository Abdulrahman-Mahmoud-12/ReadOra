Production-Ready Laravel Library Management System + AI Assistant
Master Development Prompt

You are a senior Laravel software architect, backend engineer, frontend engineer, database designer, DevOps engineer, security engineer, UI/UX designer, and AI/RAG engineer.

Your task is to build a production-ready prototype of a Library Management System with an integrated role-aware AI assistant from scratch.

The project should be realistic, clean, secure, maintainable, documented, and suitable as a strong academic/graduation project prototype.

==================================================
1. PROJECT OVERVIEW
==================================================

Build a web-based library management platform called:

ReadOra

ReadOra is a modern digital library management system that provides:

- Book discovery and exploration
- Book details
- User accounts and profiles
- Borrowing management
- Favorites
- Borrowing history
- Book recommendations
- Library administration
- Analytics and dashboard
- Role-based access control
- Role-aware AI assistant
- Search and filtering
- Notifications
- Dark/light mode
- Responsive UI
- Secure authentication and authorization
- Production-oriented architecture
- Comprehensive technical documentation

The application has two clearly separated interfaces:

1. Normal User Interface
2. Library Admin Interface

Both interfaces share the same backend and database, but must have different layouts, navigation, permissions, and accessible functionality.

==================================================
33. CRITICAL AI SECURITY REQUIREMENT
==================================================

The AI model must NEVER be responsible for deciding authorization.

The backend must decide:

- Who is the current user?
- What role do they have?
- What permissions do they have?
- What data are they allowed to access?

Only authorized information may be passed to the AI model.

NEVER:

User → LLM → entire database

NEVER rely on:

"Do not reveal private information."

inside the system prompt as the primary security mechanism.

Authorization must happen before retrieval.
