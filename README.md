# ReadOra

ReadOra is a planned production-oriented Laravel library management system with a role-aware AI assistant.

The project is being built phase by phase according to `INSTRUCTIONS.md`.

## Current Status

Phase 1 - Laravel Foundation is complete.

Start here:

- `INSTRUCTIONS.md`
- `docs/architecture/decision-log.md`
- `docs/progress/current-phase.md`

## Target Stack

- Laravel
- Blade
- Livewire
- Tailwind CSS
- Alpine.js
- MySQL or MariaDB
- NVIDIA NIM or OpenRouter through an AI provider abstraction

## Development Rule

Complete one phase, report it, wait for confirmation, then continue to the next phase.
