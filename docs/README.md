# ReadOra Documentation

This directory contains all project documentation.

## Structure

- `architecture/` — System & application architecture, decisions
- `ai/` — AI provider integration, security, RAG architecture
- `configuration/` — Environment and configuration guides
- `database/` — Schema, ERD, relationships, indexing
- `data/` — Book dataset, import pipeline, data cleaning
- `features/` — Feature specifications
- `security/` — Security architecture, auth, AI security
- `ui/` — Design system, pages, components, assets
- `api/` — API documentation
- `testing/` — Testing strategy and test cases
- `deployment/` — Deployment, environment, production checklist
- `progress/` — Phase tracking, changelog
