# ReadOra UI Components

## Base Components

| Component | File | Purpose |
|-----------|------|---------|
| `<x-button>` | `components/button.blade.php` | Styled button with variants (primary, secondary, outline, ghost, danger) |
| `<x-input>` | `components/input.blade.php` | Form input with label and error support |
| `<x-logo>` | `components/logo.blade.php` | Logo display with auto light/dark variant |
| `<x-navbar>` | `components/navbar.blade.php` | Main navigation bar |
| `<x-footer>` | `components/footer.blade.php` | Site footer |
| `<x-theme-toggle>` | `components/theme-toggle.blade.php` | Theme preference dropdown |

## Layouts

| Layout | File | Purpose |
|--------|------|---------|
| App | `layouts/app.blade.php` | Authenticated user layout |
| Guest | `layouts/guest.blade.php` | Auth pages layout |
| Admin | `layouts/admin.blade.php` | Admin panel layout |
