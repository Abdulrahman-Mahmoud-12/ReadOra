# ReadOra Design System

## Color Palette

| Token | Light | Dark | Usage |
|-------|-------|------|-------|
| Navy 800 | #1e293b | — | Primary dark elements |
| Navy 900 | #0f172a | — | Deepest backgrounds |
| Navy 950 | #020617 | — | Dark mode body |
| Gold 400 | #fbbf24 | — | Accents, hover states |
| Gold 500 | #f59e0b | — | Primary accent |
| Gold 600 | #d97706 | — | Active accent |

## Typography

- **Font**: Instrument Sans (400, 500, 600)
- **Headings**: font-semibold or font-bold
- **Body**: font-normal

## Theme Modes

- ☀️ Light — White/gray backgrounds, dark text
- 🌙 Dark — Navy backgrounds, light text
- 💻 System — Follows OS preference

Theme is persisted in `localStorage` under key `readora-theme`.
